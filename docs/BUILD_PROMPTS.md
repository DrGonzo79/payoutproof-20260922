# Phased build prompts

## Phase 1 — evidence-backed concierge

Implement a secure staff workspace for consented, redacted valuation PDFs. Add explicit claim deadlines, manual field confirmation, rule-versioned audit generation, and an append-only action log. Keep listing acquisition manual until data rights are confirmed. Add golden-file tests for five real redacted reports and do not introduce an LLM.

## Phase 2 — assisted extraction

Add malware scanning, PII redaction preview, OCR/schema extraction with page-level citations, user confirmation for every extracted vehicle/offer field, async job states, idempotency keys, and structured unsupported-document errors. Instrument correction rate and extraction failures. Preserve the manual path.

## Phase 3 — licensed evidence and outcomes

Integrate one contractually permitted listing/transaction provider behind an adapter. Snapshot provenance, capture timestamp and license constraints, deduplicate listings, implement trim normalization, and create rule-version golden tests. Add opt-in outcome follow-up and partner attribution with transparent disclosures.

## Phase 4 — reviewed report pilot

With counsel and a qualified appraiser in one state, define which outputs may be called screening, reviewed, or certified. Add reviewer queues, signatures, conflict disclosures, jurisdiction templates, SLA alerts, deletion workflows, billing/refunds, and a full incident runbook. Do not expand states until error and outcome thresholds hold.
